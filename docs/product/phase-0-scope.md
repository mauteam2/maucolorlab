# Phase 0 scope

Phase 0 creates the buildable, secure foundation for ELIFORA. It includes application shells, design tokens, environment boundaries, authentication boundaries, tenant identity tables, role and permission primitives, RLS, immutable audit events, shared API error contracts, tests, and CI.

It intentionally excludes Hair Passport, capture, Color Engine, Risk Engine, Brand Adapter, recipes, live sessions, outcomes, appointments, inventory, finance, commission, CRM, reports, AI, Try-On, customer applications, booking, commerce, messaging automation, native iOS, and hardware integration.

Environments progress through Development, Staging, Pilot, and Production. This phase uses local development data only and performs no deployment or production migration.
