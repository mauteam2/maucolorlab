# ELIFORA Chemical Compatibility Foundation

Compatibility is a versioned, sourced rule binding exact product and developer/activator versions to an application technique and context. The documented mixing ratio is a source fact of that exact product version and is snapshotted with the rule; an alternative ratio requires a new reviewed product/rule release. No rule is inferred from brand name, similar shade, developer label, stock or common salon practice.

Outcomes are `VERIFIED_ALLOWED`, `VERIFIED_RESTRICTED`, `NOT_RECOMMENDED`, `INCOMPATIBLE` and `UNKNOWN`. Verified outcomes require a source, reference, verifier and timestamp. Restricted rules must carry conditions or restrictions. The structured conditions currently supported are NO_LIFT, NO_GREY_COVERAGE and STANDARD_REGION_ONLY; they are evaluated against the authoritative regional technical requirement. Unstructured restrictions require professional interpretation and block automatic candidate readiness.

Missing, unknown, incompatible and not-recommended rules never yield a brand-ready draft. Multiple contradictory rules cannot be resolved optimistically. The database uniquely identifies product/developer/technique/context within a release; the domain also rejects ambiguity. Wrong scope provenance, inactive/unverified/deprecated developers, absent ratio/time/strength facts and invalid operating values fail closed.

Compatibility does not override Color safety. Adapter evaluation follows a fresh Risk/Color check, unresolved physical tests or critical information stop the chain, and blocked Color Plans are independently rejected by persistence if a brand-ready result is attempted. There is no executable status in Phase 2A; even verified allowed combinations remain professional-review drafts.

No manufacturer compatibility values are supplied with this phase. All controlled test values explicitly identify themselves as fictional. Real catalog publication requires official documentation or expert/salon validation with appropriate scope, a reviewed golden receipt and the full governance sequence.
