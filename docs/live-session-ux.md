# ELIFORA Live Session UX

Live is a professional workstation, not another administrative form. The current in-progress step, or the first pending step, is the visual focus; the next pending step supplies orientation. Terminal sessions display their terminal status instead of inviting an old step to run. Buttons still use the existing controller, version, permission and lifecycle guards.

## Glanceable execution

Current status, approved recipe, security state and controller ownership remain above the work. Sequence and timers have separate columns on wide screens; usage, checkpoints and notes use a lower working area. Small screens stack these sections. Controls have at least 50 px height. Superseded steps remain historical and disabled.

## Time and uncertainty

The existing calibrated clock and elapsed-time functions are unchanged. Timers remain professional reminders, show network uncertainty and do not imply an automatic processing instruction. Offline timers continue from the existing clock model. Pause, resume, completion, device recovery and controller transfer retain their authority checks.

## Materials and history

Prepared, used and waste amounts remain explicit measured inputs. Terminal reconciliation remains append-only, idempotent and auditable; empty quantities mean unknown, and measured zero remains zero. A new recipe version never rewrites executed steps or past bowls. Photos keep private storage and the existing sanitization boundary.

Status, checkpoint, risk-event, timer and photo labels are Turkish presentation strings. Command values remain unchanged. Unknown enum variants display a cautious review label rather than leaking an internal enum or implying success. Historical record references remain accessible through disclosure. Explicit professional review is still required before preparing a new session.
