# ELIFORA Color Engine pilot model

This slice starts at Phase 9 `77c20bfee4ba6c62c8f02ed7bab060a7b9764e60`.
It authorizes development verification, not production deployment or salon onboarding.

The chain remains Hair Passport → regional target → Confidence → Risk → Color Engine
→ verified Brand Adapter → professional-controlled recipe → existing Live → outcome.
There is no parallel execution system and no automatic learning from outcomes.

Color Engine **1.1.0** adds a signed, versioned qualitative target interpretation and
authoritative risk/confidence bands to every new evaluation, including non-progressing
ones. Planning thresholds, evidence qualification, safety precedence and chemistry
are unchanged. The target schema remains **1**, with the existing 1–10 scale and ten
target modes. A versioned target taxonomy is an authoring adapter, not a new lift model.

Old 1.0.0 signed payloads retain their exact bytes, fingerprints, target revisions,
catalog references and signatures. Readers accept both versions; absent historical
interpretation is not fabricated. A forward constraint migration admits 1.1.0 without
rewriting history. New evaluations include the interpretation in the HMAC envelope,
and retain fresh Hair source tokens, target revision checks, membership, entitlements,
catalog lifecycle locks, idempotency, audit and usage-event policy.

The server interprets only controlled target fields. Swatch RGB, preset names, prose,
stock availability and browser-supplied risk never become chemistry. Numeric pigment
strength remains UNKNOWN. A DRAFT remains REQUIRES_BRAND_ADAPTER; professional-entered
grams and official ratio arithmetic retain their prior boundary.

DIRECT, CONDITIONAL, MULTI_STAGE, MULTI_SESSION, INFORMATION_REQUIRED,
RECOVERY_REQUIRED and BLOCKED_BY_SAFETY_GATE remain distinct. High-risk gates cannot
produce a normal draft. Multi-session results retain the final target, current limits,
explicit professional intermediate objective where supplied, and reassessment between
sessions. Without evidence no intermediate numeric achievement is invented.

Android gains typed target construction/save/read and versioned historical plan read
through existing caller-JWT RPCs, fresh membership and DI. It does not evaluate/sign
chemistry on-device. Web is the complete target authoring surface; this slice does not
claim a new native ColorLab product screen.
