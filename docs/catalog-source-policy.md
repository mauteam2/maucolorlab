# ELIFORA catalog source policy

Only manufacturer-controlled official origins are accepted for the initial registry. Retailers, forums, social posts, distributor interpretations and third-party charts cannot establish verified chemistry. The initial collector has an explicit reviewed HTTPS host set, checks redirect hosts, content type and size, and computes SHA-256 over downloaded response bytes. It never crawls arbitrary user-supplied URLs.

`contracts/catalogs/global-discovery.json` retains manufacturer/brand/line relationships, exact requested and resolved URL, title, source class, region, language, retrieved-at UTC, byte length and SHA-256. Document date/version remain null when not established from the document; HTTP retrieval time and search-engine dates are not document dates. Raw snapshots remain in ignored `apps/web/captures/catalog-intake`; copyrighted document bodies are not committed or redistributed as product assets.

Preferred evidence is official IFU, technical guide, shade chart, developer guide and compatibility/application guide. Product pages and portfolio/index pages establish discovery only. One technical PDF was also collected; its receipt does not establish regional applicability or human technical approval. An official origin, PDF extension, familiar product name or checksum is not a chemistry validation.

Shade metadata is transcribed only where source text explicitly supplies the code/name. `5M` is not parsed into level 5 or a numeric pigment vector. `10 Volume Matrix Cream Developer` is a literal product label; listing it does not approve any shade pairing. Compatibility, ratios, processing windows and safety rules require independent reviewed evidence in the existing technical catalog workflow. No cross-brand, cross-line or industry-standard substitution is permitted.

Run `python scripts/collect-global-catalog-sources.py` only for a deliberate new intake. It reports failures individually and does not invent a checksum for failed downloads. The initial reviewed seed requires all 15 receipts. `build-global-catalog-seed.py` is an initial seed builder, not a command for regenerating applied migrations. Future evidence must get a new immutable source ID and forward migration, retaining old hashes. Source disagreements require review; they do not silently overwrite the existing IGORA pack.

Excluded attempt (not counted as a collected technical source): the former Goldwell `https://www.goldwell.com/content/dam/education/Education_PDF_All%20about%20color_GOLDWELL-ALL_2022-02-23.pdf` resolved to `https://www.goldwell.com/find-us/` with HTML on 2026-10-21. Search results were insufficient evidence of a retrievable PDF. The collector now tests MIME type and PDF magic together; HTML redirects cannot satisfy a technical-PDF source class.
