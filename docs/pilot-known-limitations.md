# ELIFORA pilot known limitations

**Pilot decision is NO_GO until hosted readiness evidence is complete.** No real
salon admission, candidate outreach or public production is authorized by this phase.

- Verified manufacturer recipe coverage is narrow: **1 brand, 1 line**, Schwarzkopf
  Professional IGORA ROYAL ABSOLUTES, **29 shades, 2 developers, 58 controlled
  compatibility rules, 3 official documents**. New verified additions: **0**.
- Broad target definition/strategy does not guarantee a verified manufacturer
  mapping, numerical pigment strength, achievable lift, exact time or executable
  recipe. The current controlled workflow is the restricted single-root refresh
  pilot with professional shade/grams selection and official ratio calculation.
- Native Android ColorLab is not full parity. No real-device/emulator smoke result
  is available in this phase; Android is excluded from pilot-critical acceptance
  until that evidence exists. Compiled instrumentation APK is not a device test.
- Web evidence is Chromium desktop/mobile profile including 320 px, not Safari or
  Firefox certification. Local/CI production build is not a hosted deployment.
- Hosted invitation/recovery mail, external domain/configuration, real isolated
  DB/Storage policies, backup/restore/key escrow and professional colorist usability
  review require external evidence. Local Inbucket or synthetic restore is not
  hosted readiness. No production-scale SLA or scientific/clinical result validation.
- ELIFORA supports professionals; it does not replace colorist authority or create
  autonomous application instructions. Feedback scores never modify engine rules.
- Offline supports the existing bounded encrypted draft/intent/recovery protocols;
  it is not unrestricted offline execution of financial or chemical commands.
- Feedback is an explicit downloadable structured document, not a hosted helpdesk
  inbox. No silent analytics/client payload collection. Support owner/channel must
  be named before admission.
- Owner Reports exports are scoped projections. Whole-tenant portable return,
  retention/legal notice approval and photo deletion/archive requests require a
  separately reviewed operator procedure; no silent ledger deletion is implemented.
- Provider invitation and application membership activation are controlled operator
  steps; no automated public salon creation or turnkey hosted team-invite email UI.
- Current signing-key rotation must preserve/migrate offline wrap-derived material;
  no multi-key verifier or automatic destructive rotation. See security-operations.
- Existing inline-script/style CSP allowance and development-only dependency
  advisories remain explicitly documented; no claim of nonce-only CSP.
